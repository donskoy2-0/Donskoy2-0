# Донской 2.0

![Обложка «Донской 2.0»](demo/art/cover.webp)

**Дмитрий Иванович Филатов** · интерактивный роман на русском, украинском и английском
[Читать книгу](https://donskoy2-0.pages.dev/) · [Демо-фрагмент в JSON](demo/data/edition.json)

Антрополог Аркадий Левшин соглашается подтвердить подлинность княжеских останков. Его подпись запускает маршрут, который приведёт его из Архангельского собора к фронту. На Земле Левшин следует за костью. На Небе князь пытается выяснить, кто позвал его по имени.

### Код читалки

| Каталог | Что внутри |
| --- | --- |
| [src/reader](src/reader/) | Отрисовка прозы, стихов и документов, цвета реплик, звук, иллюстрации, блокнот и навигация |
| [src/kernel](src/kernel/) и [canon](canon/) | Правила переходов между сценами, смена языка и возврат к прочитанному |
| [src/runtime](src/runtime/) и [src/shell](src/shell/) | Клиентский код входного экрана и последовательного чтения |
| [assets](assets/) | Шрифт, иллюстрации и звук |
| [tests](tests/) | Проверки переходов, воспроизведения звука и работы интерфейса |
| [demo](demo/) | Автономный просмотрщик двух слоёв всех 12 глав на трёх языках (по 231 знаку) |

### Запуск

Скачайте и распакуйте репозиторий. Откройте `demo/index.html` двойным щелчком. Три перевода каждой главы показаны рядом. Другой фрагмент в формате [edition.json](demo/data/edition.json) открывается кнопкой **«Открыть JSON»** или перетаскиванием в окно.

Для проверки модулей выполните `npm test` с Node.js 22 или новее. Команда `npm run build` собирает статическую публикацию в `dist/`. Установка зависимостей не требуется. Полное прохождение со звуковыми событиями и сохранением прогресса доступно [в книге](https://donskoy2-0.pages.dev/).
